# 园区智能助手 · 对话演示页

苹果官网风格(`apple.com`)的对话框交互演示页面：大标题 Hero、毛玻璃导航、圆角卡片、
克制的蓝紫渐变点缀，零依赖纯静态实现（HTML + CSS + 原生 JS）。

**这个页面只做一件事：把 loop agent 的对话跑起来给人看。**
报告生成、知识库问答、语音这些入口连同后端一起删掉了（以后按插件接入）。

## 快速开始

1. 启动后端（`uvicorn app:app --host 0.0.0.0 --port 8001`）
2. 直接用浏览器打开 `web/index.html`（纯静态、无需构建、不经后端托管）

连接地址规则：页面从 http(s) 服务打开时自动连当前域名；直接双击打开时默认连
`ws://127.0.0.1:8001`；后端不在 8001 时用 URL 参数指定，例如 `index.html?ws=ws://localhost:8000`。

**会话（session_id）存在 `localStorage`**：刷新、关标签重开都续上同一个会话，
后端因此能从 `chat_history.db` 里恢复上一轮的上下文；只有点右上角「新对话」才换新的。
想手动重开会话，清掉 localStorage 里的 `demo_session_id` 即可。

## 页面结构

```

├── index.html      # 导航 / Hero / 能力场景 / 对话区
```

## 功能说明

- **对话框交互**：WebSocket 连 `/chat/{user_id}/{session_id}`，支持流式回答、多轮追问、
  工具调用状态提示（停止按钮只在正式前端 `tf_park_ue` 里有，这个演示页不提供）
- **固定走 loop 链路**：发送时带 `mode=loop`。本分支 loop 是唯一链路，显式传是为了
  不依赖服务端 `AGENT_MODE` 的环境配置
- **九大场景入口**：人员 / 安防 / 食堂 / 车辆 / 信息 / 能源 / 会议 / 设备 / 消防，
  点击卡片或 chips 直接提问
- **场景指令入口**：切楼层、看监控、改天气等，与业务查询共用同一个输入框，由后端自动分流
- **结构化清单**：收到 `list` 事件时渲染成设备清单卡片
- **新对话**：右上角一键重置，生成并持久化新的 session_id（后端按它重新开一条会话线）
- **连接状态**：导航栏圆点实时指示连接情况，断线自动指数退避重连（最多 5 次），
  发送后连不上会提示并解锁输入
- **过程稿与最终回答分气泡**：收到 `tool` 事件时，把之前那段文字（模型"我先查一下"之类）
  单独落成一个虚线小气泡，后续流式内容进新气泡
- **链路信息条**：整轮结束时显示 `链路 L2 · 已升级 · 工具 1 次`，用来快速判断走了哪一级

## 消息协议

发送：

```
{"query": "用户问题", "mode": "loop"}
```

接收（由 `js/app.js` 解析渲染）：

| 消息 | 含义 |
|---|---|
| `{"event":"custom","data":{"type":"answer","content":"..."}}` | 回答，**追加**语义（流式分块） |
| `{"event":"custom","data":{"type":"ask","question":"..."}}` | 追问（读 `question`，不是 `content`） |
| `{"event":"custom","data":{"type":"tool","name":"..."}}` | 工具调用中 → 上段文字落成过程稿 |
| `{"event":"custom","data":{"type":"list","kind":"device","items":[...]}}` | 结构化清单 |
| `{"event":"custom","data":{"type":"error","content":"..."}}` | 错误 |
| `{"status":"done","level":"L0/L1/L2","escalated":bool}` | 整轮结束 |
| `{"error":"..."}` | 全局错误 |

注意：后端不发 `{"type":"done"}`，结束统一认 `{"status":"done"}`。

## 测试要点

| 输入 | 预期 |
|---|---|
| `3楼的门禁设备有哪些` | L1 直出，纯列表（无开场白/总结）+ `list` 清单 |
| `门禁设备在线率是多少` | L2，调用动态发现的 `devicequery__*` 工具 |
| `切到 3 楼` | 场景通道，回答只说"已下发" |
| `今天园区有多少人` | L1 `person_status` |
| 任意两条以上的跨域问题 | L2，过程稿气泡里能看到多次工具调用 |

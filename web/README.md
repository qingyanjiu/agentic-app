# 园区智能助手 · 对话演示页

苹果官网风格(`apple.com`)的对话框交互演示页面:大标题 Hero、毛玻璃导航、
圆角卡片、克制的蓝紫渐变点缀,零依赖纯静态实现(HTML + CSS + 原生 JS)。

## 快速开始

1. 用你自己的方式启动后端（Docker 或 uvicorn）
2. 直接双击打开 `web/index.html`，或用任意静态服务器托管 —— 纯静态、无需构建

连接地址规则：页面从 http(s) 服务打开时自动连当前域名；直接双击打开时
默认连 `ws://127.0.0.1:8001`；后端不在 8001 时带参数指定，
例如 `index.html?ws=ws://localhost:8000`

## 页面结构

```
web/
├── index.html      # 页面结构:导航 / Hero / 能力场景 / 对话区
├── css/style.css   # 苹果风格样式(毛玻璃、气泡、动效、响应式)
└── js/app.js       # WebSocket 对话逻辑与轻量 Markdown 渲染
```

## 功能说明

- **对话框交互**:通过 WebSocket 连接 `/chat/{user_id}/{session_id}`,
  支持流式回答、多轮追问、工具调用状态提示
- **知识库问答**:输入区上方切换「智能体问答 / 知识库问答」,知识库模式
  消息带 `mode=kb`，由后端跳过意图分类直达 RAG 管线（需后端支持该参数）
- **Loop 新链路**：第三个按钮发 `mode=loop`，强制命中灰度新链路（L0/L1/L2 三级分流 +
  动态发现的 MCP 工具），用来对照新旧链路的行为差异
- **九大场景入口**：人员 / 安防 / 食堂 / 车辆 / 信息 / 能源 / 会议 / 设备 / 消防，
  点击卡片或 chips 直接提问
- **新对话**：右上角一键重置，生成新 session_id
- **连接状态**：导航栏圆点实时指示 WebSocket 连接情况，断线后自动指数退避重连（最多连续 5 次），发送后连不上会提示并解锁输入
- **流式体验**：回答逐字渲染带闪烁光标，状态条展示意图理解/工具调用进度
- **过程稿与最终回答分气泡**：收到 `tool` 事件时，把之前那段文字（模型"我先查一下"之类）
  单独落成一个虚线小气泡，后续流式内容进新气泡——两者不再混成一坨
- **链路信息条**：loop 链路结束时在对话下方显示 `链路 L2 · 已升级 · 工具 1 次`，
  用于验证灰度分流；旧链路不带 `level`，不显示

## 消息协议

发送：

```
{"query": "用户问题"}
{"query": "用户问题", "mode": "kb"}    知识库直连
{"query": "用户问题", "mode": "loop"}  强制走 loop 新链路（灰度测试）
```

接收（由 `js/app.js` 解析渲染）：

| 消息 | 含义 |
|---|---|
| `{"event":"custom","data":{"type":"answer","content":"..."}}` | 回答，**追加**语义（流式分块） |
| `{"event":"custom","data":{"type":"ask","question":"..."}}` | 追问（读 `question`，不是 `content`） |
| `{"event":"custom","data":{"type":"tool","name":"..."}}` | 工具调用中 → 上段文字落成过程稿 |
| `{"event":"custom","data":{"type":"intent_desc"}}` | 意图理解进度 |
| `{"event":"custom","data":{"type":"error","content":"..."}}` | 错误 |
| `{"status":"done","level":"L0/L1/L2","escalated":bool}` | 整轮结束（旧链路只带 `status`） |
| `{"event":"on_tool_start"|"on_tool_end"}` | LangChain 生命周期（旧链路） |
| `{"error":"..."}` | 全局错误 |

注意：后端不发 `{"type":"done"}`，结束统一认 `{"status":"done"}`。

## 测试要点（loop 新链路）

切到「Loop 新链路」后重点验这几类：

| 输入 | 预期 |
|---|---|
| `3楼的门禁设备有哪些` | L1 直出，纯列表（无开场白/总结） |
| `门禁设备在线率是多少` | L2，调用 `devicequery__getMjOnlinePercentage` 这类动态发现的工具 |
| `关闭监控窗口` | L0 handoff，看不到"没有这个能力"，交给旧链路走场景 |
| `能打开监控吗` | L0 handoff（问句形式的场景指令） |
| `今天园区有多少人` | L1 `person_status__query` |
| 任何两条以上的跨域问题 | L2，过程稿气泡里能看到多次工具调用 |

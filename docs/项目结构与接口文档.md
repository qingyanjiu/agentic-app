# 路由与接口对照文档

> 聚焦版：仅含「一级路由 + 二级路由」与「页面小模块 → 接口 → 返回格式 → 数据说明」。
> 更新日期：2026-08-21 · 分支：main
>
> 格式说明：**返回格式** 指 HTTP 响应 `data` 字段的 TypeScript 类型；`HttpResult = { status: "1"|"0"; msg: string; data }`，`status === "1"` 为成功。**数据说明** 描述该模块展示什么数据、各字段业务含义。路由为 hash 模式。

---

## 一、路由结构（一级 → 二级）

| 一级模块 | 一级路径 | 默认落点(redirect) | 二级路由（路径 · name · 标题） |
|---|---|---|---|
| 综合态势 | /compositive | /compositive/overview | overview · Overview · 综合态势；personnel · Personnel · 人员态势；vehicle · Vehicle · 车辆态势*；energy · Energy · 能源态势；event · Event · 事件态势 |
| 安全应急 | /emergency | /emergency/security | security · Security · 安防态势；fire · Fire · 消防态势；perimeter · Perimeter · 孪生周界；command · Command · 孪生指挥；aiAlert · AiAlert · AI预警 |
| 智能运营 | /operation | /operation/dining* | dining · Dining · 食堂管理；meeting · Meeting · 会议管理；twinVisitors · TwinVisitors · 孪生访客 |
| 孪生应用 | /twins | /twins/inspection | inspection · Inspection · 孪生巡检；monitor · Monitor · 孪生监控；trace · Trace · 轨迹回溯 |
| 基础服务 | /services | /services/information | information · Information · 信息发布；device · Device · 设备态势；network · Network · 网络管理 |
| 开发管理 | /dev | /dev/test | test · Test · 测试管理（`meta.hidden`） |

- \* vehicle 为容器页，含三级子路由：carStatistic（公车统计）、parkingRank（停车时长排名）、parkingLot（停车场监控）
- \* /operation 原配置 redirect 为 /operation/canteen（无此路由），运行时会自动修正为 /operation/dining
- 动态路由当前为空；`/security/monitor` 页面已建但未挂路由（开发中）
